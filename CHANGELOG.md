# Changelog

## 1.0.1

Packaging-only correction: removed seven redundant stock BO7 image exports. The mod references the built-in game materials directly. No gameplay changes.

## 1.0.0

Initial public release of BO7 Recrudescence. Includes the expanded Arsenal, attachment/conversion support, augment purchases, 2,412-camo catalogue, 72-weapon no-repeat Mystery Box, extended upgrades, and zombie/points balance changes.

The production Arsenal retains the required HUD input-routing override; logging and dedicated developer probes are excluded.
